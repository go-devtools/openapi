# 当前状态

完整 Goal 仍在实现，尚未完成最终产品验收。两个产品分别位于独立 Git 根和 Go module；远端保持 private，本地与远端默认分支均为 main。精确开发工具链为 Go 1.27.1，Gin 依赖固定 v1.12.0。

## 代码与公开边界

自有代码注释同时提供简体中文和英文，生成器也输出双语注释。示例中贴近声明的 OpenAPI 文档继续使用英文。README.md 为英文，README.zh-cn.md 为中文，自有代码采用 MIT；第三方资源、许可证及编译指令保留原文。已授权的历史提交说明翻译保留代码树、作者、提交者与时间；原始 Git bundle 和映射已验证，此后使用普通快进英文提交。

核心公开类型加载、Schema 投影、通用前端、调用返回备选、有限请求条件、版本化 Bundle、运行时构建、独立 Schema 导出、离线资源和可选验证/UI API。核心及测试依赖树没有 Gin/Fiber/Echo/适配器依赖；根运行时包不引入编译器、UI 或独立测试引擎。外部消费者只导入公开 SDK。

## 最近已验证能力

有限请求条件贯通 CallOutcome.When、Bundle 变体和中立 Route 链接。互斥方法/媒体不互相污染诊断，多媒体 Schema 备选保留约束；参数或请求体必填状态无法准确合并时明确失败。Gin 的自动绑定、显式绑定与强制错误提交由适配器维护。

构建输入现在使用实际加载目标，纳入 overlay 快照、包内文件身份、非当前构建源码、嵌入与非 Go 文件、有效模块/替换声明、工作区本地源码、架构/CGO/实验开关、codec 和集中映射配置。项目迁移目录保持相同生成字节。参数和自定义配置只公开摘要；不执行外部 packages driver 或工具包装器，不接受可写模块模式。详细规则见[构建输入指南](build-inputs.md)。

上一构建输入阶段的核心 dev、完整 race、vet 和模块校验通过；25 项外部 SDK 开发测试覆盖公开编译与输入边界。Gin 的集中 mapper 配置与自动媒体范围开发联调通过。开发 workspace/本地 replace 的证据与发布后真实固定版本的证据分别记录，不能混称；历史冷缓存结果只证明当时的阶段版本。

共享 Swagger UI 的既有示例包括五种 HTTP 方法、Deprecated、Bearer 授权、枚举含义、字段类型和五份整体分类；标签筛选关闭，内部 Schema 身份不显示在模型标题中。业务 handler 和路由的无侵入验证、浏览器记录及精确版本见[验证记录](verification.md)。
