## 已有实现与实证

- 公开中立 SDK、源码和类型加载、输入输出 Schema 投影、前端效果、版本化 Bundle、轻量运行时构建和原生 OpenAPI 3.2 模型已连接。核心依赖边界与真实外部 module 消费有测试。
- 显式离线资源检查、资源身份和锚点、组件裁剪、结构约束、来源注释冲突及累计预算有正反例。可选 contracttest 使用独立引擎验证 JSON、动态递归以及流式样本；不会按 URI 自动读取网络或文件。
- 独立 Schema 导出支持按资源作用域转换组件引用、保留方言和精确数值、嵌入明确提供的依赖及输出预算。CLI 复用离线清单并保护已有输出；独立引擎、外部 SDK、并发只读及 URI 模糊验证见[验证记录](verification.md)，用法见[导出指南](standalone-schema.md)。
- Gin 示例从无新增 tag 的源码生成 Bundle，在启动层挂载共享离线 Swagger UI。真实 HTTP 契约测试检查挂载前后的状态、头和 body；业务 handler 与路由函数体经过 AST 对比。
- 英文示例包含完整字段类型、枚举值说明、五种 HTTP 方法、Deprecated、Bearer 授权和五份整体分类。标签筛选框已关闭；模型展示隐藏内部身份后缀。既有浏览器记录覆盖桌面、移动布局与离线加载，不代表所有后续提交都重新进行了浏览器验收。

两仓库此前已在各自仅含本仓库源码、初始空模块和构建缓存、关闭 workspace 的环境中，完成指定远端版本的 dev、race、vet、CLI 安装与独立消费。精确 SHA、版本及首次冷下载超时后的复验过程保留在两仓库验证记录中。这些是阶段版本的实证；当前依赖以适配器 go.mod 为准，不能替代最终版本验收。
