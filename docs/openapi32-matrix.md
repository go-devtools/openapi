# Native OpenAPI 3.2 support matrix

Model availability, serialization, semantic checking, independent instance validation, and UI rendering are separate capabilities. The table identifies existing tests and the limits of their coverage; a roundtrip fixture alone does not establish every positive and negative combination.

| Area | Public expression/model | Current evidence | Coverage limits |
| --- | --- | --- | --- |
| Root, `$self`, dialect, references | `spec.OpenAPI`, `spec.Ref`, Schema references | `spec/model_test.go`, offline reference tests and `docs/references.md` | Complete base-URI and external-reference matrix; UI behavior |
| Metadata and components | `spec.Info`, `Contact`, `License`, `Components`; [rules](native-objects.md#document-metadata-and-component-names) | Public/official presence, field/type, mailbox/URI, license exclusivity and all eleven component-name matrices; empty required-string roundtrip and offline resource checks | SPDX expression/registry validation and metadata URI edge-case completeness; empty Request Body content explicitly rejected |
| HTTP methods | `spec.PathItem.Query`, `AdditionalOperations` | Public/official fixed-field, HTTP-token and case-sensitive custom-method matrix; operation metadata and container checks | [UI contract](swaggerui-compatibility.md): QUERY renders and submits exact bytes when explicitly enabled; custom methods are omitted by upstream and listed in compatibility diagnostics, with submission rejected |
| Endpoint paths | `spec.OpenAPI.Paths`, `PathItem`; [template rules](native-objects.md#endpoint-path-templates) | Public/official grammar matrix; duplicate expressions, same-hierarchy conflicts, every-operation bindings, offline aliases, component use sites and budgets | Runtime matching of otherwise ambiguous routes, parameter-value serialization and percent-equivalence normalization |
| Parameters | `spec.Parameter` and public compiler effects | Public/official location/style/content/boolean matrix; required empty name roundtrip; referenced duplicates, path inheritance, operation overrides, query conflicts, external aliases and cycle/budget tests; independent codec samples | Arbitrary style/Schema satisfiability and complete runtime serialization matrix; [whole-query UI](swaggerui-compatibility.md) retains details and blocks the measured lossy submission |
| Media types | `spec.MediaType`, shared component media types | Native roundtrip, reusable media references, public/official shape matrix, description/schema/itemSchema checks | [Item Schema UI](swaggerui-compatibility.md): separate request/response item panels, reusable media references, boolean schemas and finite stream bytes verified; arbitrary codecs and incremental stream rendering remain unverified |
| Multipart | `spec.Encoding`, prefix/item encoding; [rules](native-objects.md#media-and-multipart-encoding) | Public/official field/container/style/boolean and named/positional conflict matrix; structural array proof through ordinary offline references and composition; nested Header references; actual raw-field/file SDK tests | Arbitrary array satisfiability/dynamic scope, complete contentType grammar and multipart wire/UI projections |
| Responses and HEAD | `spec.Response.Summary`, optional description, headers/content/links | `TestHEADResponseProjection`, `TestNamedResponseComponents`, real Gin HTTP matrix | External Response Object resolution for HEAD; complete independent/UI matrix |
| Tags | `spec.Tag`, optional Parent; [migration](native-objects.md#tags-and-parent-presence) | Public/official field/container matrix; unique names, missing parents/cycles, explicit empty identities, long bounded hierarchies, externalDocs and extension opacity | [UI contract](swaggerui-compatibility.md): native values are listed in compatibility diagnostics; upstream retains flat name/description groups, without hierarchical navigation |
| Examples | `spec.Example`, Schema examples | Native fixture, public/official native-object matrix, explicit null/false/zero preservation, paired logical/wire values and offline resources; actual body-example UI selection and exact JSON/XML/text submissions, SSE response text, immutable native document | Full wire validation; parameter/header/form/external-example UI and non-JSON data-only codecs |
| Discriminator | `spec.Discriminator`; [context rules](native-objects.md#discriminator) | Typed roundtrip; public/official structural and semantic matrix; union membership, fallback, alias/anchor/offline inheritance and cyclic budget checks; independent known/unknown/omitted payloads, oneOf/anyOf and parent validation | Conservative explicit required-property proof; no arbitrary satisfiability or dynamic-scope proof; native UI matrix |
| XML | `spec.XML`; [static naming scope](native-objects.md#xml) | Typed roundtrip; public/official field/container/nodeType/namespace/legacy conflict matrix, including explicit false; content use-site names, ordinary offline references, property arrays/tuples and cyclic traversal budgets | Dynamic/instance-dependent annotation collection, Encoding content types, XML wire codec and native UI combinations |
| Security | `spec.SecurityScheme`, OAuth models; [typed construction](security-models.md) | Public/official positive-negative matrix for all five flows, field applicability/types, empty scopes, metadata, deprecation presence and extension opacity | [Security UI](swaggerui-compatibility.md#native-security-metadata): native endpoints, metadata and deprecation displayed; device grant/discovery explicitly unavailable; actual local Bearer submission verified. Runtime relative URL/server TLS and external OAuth exchanges remain unverified |
| Callbacks, webhooks, links, servers | Public typed models; [HTTP contracts](native-objects.md#http-objects-and-parameter-contexts) | Native field/container positive-negative matrix; server template/default/enum rules; opaque Link data; operationId resolution and uniqueness across offline documents; callback and operationRef contexts | Callback expression evaluation, substituted server URL validation and runtime Link URL disambiguation |
| Request/response comments | Actual types through `Project.TypeIn`; shared frontend projection | Real-source declarations, generic references, imported DTO metadata, conflicts, conditions, and independent SDK sample validation | Unknown helpers retain diagnostics; conservative Schema comparison; packages mentioned only in comments must be explicitly loaded |
| JSON Schema | `spec.Schema` and public Schema compiler | Schema tests, independent contract engine, external SDK | Complete Go projection/tag/codec/numeric/nullability matrix |
| Streams | `spec.MediaType.ItemSchema` and Schema content fields | Native model fixture; neutral ResponseItem frontend, boxed payload/commit snapshots, independent NDJSON/SSE UTF-8 and budget tests; separate Gin SSE/Stream and JSON Encoder HTTP matrices | Remaining writer/framing/async combinations, complete protocol/budget matrix and UI |

Response.description is optional in OpenAPI 3.2. The validator checks the types of present summary/description fields. Component response names are not HTTP status codes, and an `x-` component name must still be validated as a response.

Run `GOWORK=off make dev` for the module tests and build. Framework-specific behavior is tested separately in the Gin adapter. See the linked guides before depending on a feature outside the listed coverage.
